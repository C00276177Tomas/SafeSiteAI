AI Construction Site Monitoring - Alpha Release 🚧👷‍♂️
Welcome to the alpha release of the AI Construction Site Monitoring system! This project uses state-of-the-art machine learning model to detect whether workers on a construction site are wearing helmets 
and high-visibility jackets in real-time video streams.

🎯 Project Overview

This tool is designed to enhance safety on construction sites by automatically monitoring compliance with safety protocols. It currently supports:

Helmet detection
No helmet detection
High-visibility jacket detection
People detection
The alpha version demonstrates the basic functionality of the model and its real-time processing capability.

🚀 Features in This Release

Real-time video inference.
Basic detection of helmets, no helmets, people and high-vis jackets.
Pretrained YOLO model fine-tuned for this use case.

📋 Installation Instructions

Prerequisites
Python 3.8 or newer
Required libraries: ultralytics, opencv-python
