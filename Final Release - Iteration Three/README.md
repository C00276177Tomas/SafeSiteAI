AI Construction Site Monitoring - Final Release 🚧👷‍♂️
Welcome to the final release of the AI Construction Site Monitoring System! This project utilises advanced machine learning models to ensure safety compliance on construction sites by detecting whether workers are wearing helmets and high-visibility jackets in real-time video streams.

🎯 Project Overview
The AI Construction Site Monitoring system is designed to automatically monitor compliance with essential safety protocols on construction sites. The system detects:

Helmet Detection: Identifies whether workers are wearing helmets.

No Helmet Detection: Flags workers not wearing helmets.

People Detection: Detects the presence of workers in the video stream.

This release marks the culmination of the system’s development, now equipped with accurate detection capabilities, optimised performance, and scalability for real-world deployment.

🚀 Features in This Final Release
Real-Time Video Inference: Seamless monitoring of workers through live video feeds.

Enhanced Detection: Accurate detection of helmets, people, and no helmets, even under varying lighting conditions.

YOLO Model: A pretrained YOLO model fine-tuned for construction site safety monitoring, ensuring high precision and speed.

Cross-Platform Support: Compatible with various operating systems to ensure accessibility.

📋 Installation Instructions
To get started with the AI Construction Site Monitoring system, follow the steps below:

Prerequisites
Python 3.8 or newer.

Required Python libraries:

ultralytics

opencv-python

You can install the required libraries using pip:

pip install ultralytics opencv-python

Setup
Clone or download the project repository.

Install the necessary dependencies as listed above.

Run the detection system on your local machine or integrate it into your construction site video feed.
